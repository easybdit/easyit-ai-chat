# Changelog — WP Easy AI Chat

## [1.0.0] — 2025-05-12

### Added
- Initial release by [EasyIT](https://easyit.com.bd)
- Shortcode `[easyai]` — shortest possible, easy to remember
- Multi-provider: Ollama, OpenAI, Anthropic (Claude), DeepSeek
- ChatGPT-style UI: dark sidebar, sessions, conversation history
- Persistent multi-turn conversations in WordPress DB
- Markdown: code blocks, bold, italic, lists, headings
- Guest chat via first-party cookie sessions
- Rate limiting: 20 req / 60s per user or guest
- GDPR privacy notice with Privacy Policy link
- Configurable data retention (auto-purge)
- Admin tabbed settings page
- Test Connection button per provider
- Admin Test Chat page
- Fully responsive layout
- GPL-2.0-or-later license
- WordPress.org compliant readme.txt
